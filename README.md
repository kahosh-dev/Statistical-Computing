
### What each script contains
- Brief theoretical reminder  
- Mathematical formulation (in comments / print statements)  
- Worked example with synthetic or built-in data  
- Statistical output  
- Visualisation (saved to `data/`)  
- Short interpretation  

### How to run
```bash
cd python_codes
python 01_central_tendency_dispersion.py
python 08_linear_regression.py
# etc.
```
